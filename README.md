Physical Ocean Simulation 

A real-time browser-based ocean simulation focused on physically motivated wave and boat dynamics.

The simulation combines a spectral ocean model with Gerstner wave reconstruction and a physics-based floating boat model. The ocean surface is generated from a Pierson–Moskowitz wave spectrum and evolves continuously in real time. Wave numbers are obtained from the linear dispersion relation, including finite-depth effects.

Physics Model
Ocean Waves

The wave spectrum is generated from the Pierson–Moskowitz formulation using wind speed as the primary parameter.

Individual spectral components are sampled over a range of angular frequencies and assigned a directional distribution. Each component contains:

Wave direction

Wave number

Amplitude

Angular frequency

Random phase

The resulting surface is reconstructed using a Gerstner-style formulation.

Finite Water Depth

Wave numbers are calculated by solving the linear dispersion relation:

ω² = gk tanh(kh)


where:

ω = angular frequency

k = wave number

h = water depth

g = gravitational acceleration

Newton iteration is used to solve for k.

The implementation also calculates group velocity and uses it when adjusting wave amplitudes for finite-depth effects.

Wave Limiting

The significant wave height is estimated from the zeroth spectral moment:

Hs = 4√m₀


The simulation limits wave height according to a depth-dependent breaking criterion and also limits total wave steepness to maintain a stable surface.

Stokes Drift

The simulation estimates the Stokes drift generated by the wave field and incorporates it into the boat's relative water velocity.

Boat Physics

The boat is not simply positioned on top of the waves. Its motion is calculated from forces acting on a discretized hull.

The hull is divided into multiple surface cells and buoyancy is numerically integrated across these cells.

The buoyancy force is based on displaced volume:

F = ρgdA


The simulation also accounts for:

Vertical buoyancy

Wave-surface slope

Pitch torque

Roll torque

Vertical hydrodynamic damping

Forward resistance

Lateral resistance

Wind force

Throttle force

Stokes drift

As a result, the boat responds dynamically to the changing wave surface instead of following a predefined animation.

Rendering

Rendering is implemented with Three.js and WebGL.

The ocean surface uses a custom ShaderMaterial. Wave displacement is performed directly in the vertex shader, while the fragment shader calculates water appearance using the generated surface normal, view direction and reflected environment.

The water shader includes:

Dynamic vertex displacement

Analytical surface normals

Fresnel-based reflection

Procedural sky reflection

HDR-like sun highlights

Distance-based atmospheric blending

The ocean mesh is continuously offset around the boat to provide a large navigable water area without requiring an extremely large world-space mesh.

The HUD exposes two main environmental parameters:

Changing these parameters rebuilds the wave spectrum and updates the resulting ocean state.

Running

The project is intentionally lightweight and consists of a single HTML file.

Clone the repository:

git clone https://github.com/bdrnex-tech/Physical-Ocean-Simulation.git
cd Physical-Ocean-Simulation


Then open index.html in a modern WebGL-capable browser.

No build system or package installation is required.
